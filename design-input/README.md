# Design-Eingang (Operator → Agent)

Lege hier deine fertigen Poster-Designs ab — ich übersetze sie in eine
Design-Vorlage der Registry (`src/designs/`), die sich automatisch mit den
echten berechneten Daten jedes Kunden personalisiert (Vorschau + Druck-PDF,
Design-TÜV inklusive).

**Akzeptierte Formate:** PNG/JPG (auch Foto/Scan), PDF, SVG, Figma-Export.
Je höher die Auflösung, desto genauer die Übersetzung.

**Hilfreich dazu (eine Notiz reicht, formlos als .txt/.md daneben):**
- Wo sollen die dynamischen Elemente sitzen? (vier Säulen, Tagesmeister,
  Name, Element/Tier, ggf. Untertitel)
- Welche Flächen sind fix (Illustration/Ornament) und dürfen nicht weichen?
- Gewünschter Name des Designs im Wähler.

Dateien hier werden committet (Repo-intern). Nach der Übersetzung bekommst du
eine Live-Vorschau im Design-Wähler zur Freigabe.
